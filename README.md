# Lost and Found Management System

A comprehensive C-based management system for tracking and managing lost and found items. This project provides a complete solution for organizations to efficiently handle claims, categorize items, manage staff, and resolve cases.

## Overview

The Lost and Found Management System is designed to streamline the process of managing items reported as lost or found. It provides an interactive menu-driven interface for various operations including managing found items, lost items, claims, staff, and case resolution.

## Features

- **Actions Management** - Define and manage various actions within the system
- **Category Management** - Organize items by categories for better tracking
- **Claims Processing** - Handle and process claims for lost and found items
- **Found Items Tracking** - Maintain a database of items that have been found
- **Lost Items Tracking** - Log and track items reported as lost
- **Resolved Cases** - Keep records of resolved lost and found cases
- **Staff Management** - Manage staff members using a circular linked list data structure
- **Interactive Menu** - User-friendly command-line interface for all operations
